# 🎬 TTomorrow Studio — Workspace sửa video, ảnh & viết content bằng Claude

Workspace cho **Claude Code** (ứng dụng Claude Desktop → tab Code) giúp người **không biết IT** sửa video, sửa ảnh, làm phụ đề, dựng video từ ảnh, viết prompt ảnh/video AI và viết content mạng xã hội — chỉ bằng cách nói chuyện tiếng Việt.

👉 **Người dùng: đọc [`BAT-DAU-O-DAY.md`](BAT-DAU-O-DAY.md).**
👉 **Người quản lý: đọc [`HUONG-DAN-QUAN-LY.md`](HUONG-DAN-QUAN-LY.md).**

## Làm được gì
- 🎬 Cắt, ghép, đổi khung 9:16 / 16:9 / 1:1 / 4:5 (nền mờ), nén, tua, nhạc nền tự giảm khi có người nói, chuẩn âm lượng, logo, chữ tiếng Việt, GIF.
- 💬 Phụ đề tiếng Việt **chạy offline** (faster-whisper), tự sửa chính tả, đốt vào video kiểu TikTok.
- 🖼️ Xóa nền **offline** (rembg), đổi cỡ theo kênh (Shopee, TikTok, Facebook, YouTube...), chèn chữ/logo hàng loạt, ghép ảnh trước–sau, HEIC → JPG.
- ✨ Dựng video từ ảnh: zoom chậm, chuyển cảnh, chữ từng cảnh, nhạc.
- 🤖 Viết prompt ảnh/video AI (Gemini/Nano Banana, ChatGPT, Veo, Sora, Kling) theo thư viện mẫu.
- ✍️ Caption, kịch bản phân cảnh, lịch đăng bài — theo bộ nhận diện thương hiệu.
- ✂️ Cắt khoảng lặng/câu lặp trong dự án CapCut (thử nghiệm).

## Cài đặt nhanh (Windows)
1. Cài Claude Desktop, đăng nhập.
2. Tải repo (Code → Download ZIP), giải nén vào `C:\TTomorrow-Studio`.
3. Nhấp đúp `CAI-DAT.bat` (tự cài uv + Python 3.12 + thư viện + mô hình AI, không cần quyền admin).
4. Claude Desktop → tab **Code** → chọn thư mục → gõ `menu`.
